# Weather Dashboard

A simple weather dashboard app that shows current conditions and a 5-day forecast.

## Live Demo

https://rajudeshya.github.io/Weather-Dashboard/

## Features

- Search weather by city
- Use current location
- View current weather details
- See 5-day forecast
- Light/dark theme toggle

## Tech Stack

- HTML
- CSS
- JavaScript
- OpenWeatherMap API

## Run Locally

1. Open the project folder.
2. Open `index.html` in a browser, or
3. Run a local server in the project folder.

## Notes

To enable live weather data, add your OpenWeatherMap API key in `script.js`.
